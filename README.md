# 📚 Media Library Management System

A web-based Media Library Management System built with PHP using the Model-View-Controller (MVC) architectural pattern. The project aims to organize media-related information and provide a structured foundation for managing a media library.

## ✨ Features

- **MVC Architecture** — Separates application logic, data handling, and presentation.
- **Organized Code Structure** — Keeps application components organized and maintainable.
- **Database Integration** — Designed for managing application data through a database.
- **Web-Based Application** — Built with PHP for local web server development.

## 🚀 Getting Started

### Prerequisites

Make sure you have installed:

- [XAMPP](https://www.apachefriends.org/) or another PHP development environment
- PHP
- MySQL
- [Git](https://git-scm.com/)

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/kklovesdaisy/Media-Library.git
```

**2. Move the project into your web server directory**

For XAMPP, place the project inside:

```text
C:\xampp_new\htdocs\Media-Library
```

**3. Start Apache and MySQL**

Open the XAMPP Control Panel and start the Apache and MySQL services.

**4. Configure the database**

- Open phpMyAdmin at `http://localhost/phpmyadmin/`.
- Create the database required by the project.
- Import the project's SQL file if one is provided.
- Update the database connection settings to match your local environment.

**5. Run the application**

Open your browser and visit:

```text
http://localhost/Media-Library/
```

If the project uses a different entry point or URL structure, adjust the URL accordingly.
